# XBeach_NorthBeach

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.15104233.svg)](https://doi.org/10.5281/zenodo.15104233)

Code and workflows used to generate XBeach model results for North Beach, Sandy Hook, New Jersey, supporting the manuscript:

> Increasing frequency of coastal erosion indicated by a hindcast model of storm-driven forcing calibrated with beach stratigraphy
